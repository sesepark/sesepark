# 박세환 · Sehwan Park

서울대학교 자유전공학부 25학번으로, 전기정보공학을 전공하고 있습니다.
휴머노이드 로봇 팀 [SHAPE](https://github.com/snu-shape)에서 활동하며 로봇 원격조작과 시연 데이터 수집·학습을 다루고 있습니다.

## 관심 분야

- 로봇팔·휴머노이드 텔레오퍼레이션
- 시연 데이터 수집과 모방학습
- 로봇 실험을 위한 제어·데이터·학습 도구

## 로봇 활동

### 팀 프로젝트

- **[AI Worker 휴머노이드 챌린지](https://github.com/sesepark/ai-worker-humanoid-challenge)**<br>
  ROBOTIS AI Worker 팀 프로젝트에서 원격 조작 화면, 카메라 연동, 주행 패널과 리더암 제어를 담당했습니다.

### 개인 프로젝트

- **[SO-ARM101 Console](https://github.com/sesepark/soarm101-console)**<br>
  브라우저·휴대폰에서 로봇팔을 조작하고 시연을 기록하는 콘솔입니다. 물리 리더 없이 3D 팔을 움직여 조작하는 모드도 구현했습니다.
- **[xArm7 Teleop](https://github.com/sesepark/xarm7-pi0-teleop)**<br>
  GELLO 리더암·휴대폰으로 xArm7을 조작하고, LeRobot 형식으로 시연을 수집해 OpenPI pi0 학습·재생으로 연결한 실험 환경입니다.
- **[sparkq](https://github.com/sesepark/sparkq)**<br>
  DGX Spark와 Mac에서 GPU 작업을 순서대로 실행하고 로그·진행 상황·체크포인트를 관리하는 큐입니다.

데이터 검토와 실험 관리는 직접 만든 개인용 맥 앱에서 하고 있습니다.
주로 ROS 2, LeRobot, OpenPI, Python, PyTorch를 사용합니다.
